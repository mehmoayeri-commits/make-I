# Make I
1. Upload de uitgepakte bestanden naar een nieuwe GitHub-repository.
2. Importeer de repository in Vercel (framework: Other).
3. Voeg onder Environment Variables OPENAI_API_KEY toe met je geheime sleutel en ACCESS_CODE met een zelfgekozen lange toegangscode voor vrienden.
4. Deploy. Deel de website-URL en de toegangscode, nooit de API-sleutel.
Optioneel: OPENAI_MODEL (standaard gpt-4.1-mini).
API-gebruik kost geld. De toegangscode is een eenvoudige toegangsbeperking, geen volledige beveiliging of kostenlimiet. Deel alleen met vertrouwde personen. Stel verbruiksmeldingen in en controleer gebruik. Voor openbare toegang zijn accounts, rate limiting en harde gebruikslimieten nodig. Chatgeschiedenis blijft alleen tijdens de sessie beschikbaar. Geen webzoekfunctie. Live API en deployment zijn niet getest.
